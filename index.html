Selected Projects in Data Science and Machine Learning

Solar Flux Forecasting: Hybrid Machine Learning and Signal Decomposition Pipeline

This project implements a robust pipeline for forecasting F10.7 solar radio flux by integrating Discrete Wavelet Transforms (DWT) with advanced feature engineering. It utilizes both k-Nearest Neighbors (k-NN) regression to perform multi-step recursive forecasting, capturing complex solar cycles and short-term fluctuations for accurate daily predictions.

Learning to Pursue: Reinforcement Learning for Pursuit–Evasion Dynamics

We study a pursuit–evasion problem in which a reinforcement learning agent learns optimal interception strategies in a continuous environment using Proximal Policy Optimization (PPO). Unlike standard pursuit problems where the target's position is always known, this environment introduces discrete observations. The agent must strategically decide when to "peek" at the target's location, balancing its limited observation budget against the increasing uncertainty of the target's path.

Key Features

  • Stochastic Target Dynamics: Supports standard Brownian motion and heavy-tailed Lévy walk target movements.
  • Custom Gymnasium Environment: Built using the Gymnasium API with a continuous action space (wait time) and a multi-dimensional observation space.
  • Policy Gradient Training: Utilizes Proximal Policy Optimization (PPO) via Stable-Baselines3 to converge on an optimal tracking policy.
